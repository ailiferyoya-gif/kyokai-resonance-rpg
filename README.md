# 境界共鳴 — Playable Web Build v1.1

iPhone幅を中心に設計した、基本オート戦闘のソーシャルRPGプロトタイプです。

## 実装済み

- 5人チーム編成（所持指揮官の入れ替え・並び替え）
- 3章9任務を順番に踏破するキャンペーン、初回クリア報酬、進行解放
- 5分ごとに1回復するスタミナ（ブラウザを閉じている間も経過分を反映）
- キャラクターLv（1–50）と、通常スキル・パッシブスキルLv（1–10）
- キャラごとに独立した武器・防具・装飾品
- 5人全員の育成値・個別装備を使うオート任務
- 3話のイベントストーリー、初回読了報酬、専用の3段階オート任務
- イベントポイントの4段階累積報酬と、専用通貨「祭札」を使う交換所
- イベント任務からデイリー作戦・ギルド共同任務へ同時に反映される横断進行
- 画像生成した九尾の祭礼機「祭禍機ヨルカグラ」のイベント専用アート
- 1日3回、5人完全オートで挑む期間限定共闘レイド「ヨルカグラ共鳴戦」
- 九尾封輪・白磁神楽面・祈願共鳴核の優先指定、部位破壊効果、追加報酬
- 全体HPに応じた3段階のフェーズ変化と、個人累積ダメージ報酬
- 1日1回の団員支援と、個人ダメージを反映する団内イベントランキング
- 3回の挑戦回数で遊べる非同期ワールドレイド
- 白磁面・境界核の優先攻撃、部位破壊効果、破壊素材報酬
- 全体HP、個人累積ダメージ、3段階の貢献報酬
- 日付変更時に参加証だけを3へ自動回復（累積ダメージと部位状態は保持）
- 5対5の完全オート非同期PvPアリーナ
- 3段階の模擬防衛データ、レート増減、勝敗・連勝・直近戦績
- 1日5回のアリーナ挑戦回数（日付変更時に自動回復、兵力消費なし）
- 任務・探索・レイド・アリーナを横断する4つのデイリー作戦
- ガチャを必須にしない個別報酬・全達成報酬と日付変更時の自動リセット
- 7日周期のログイン補給と継続日数
- 各コンテンツと育成で経験値を得るプレイヤーLv成長（Lvアップ報酬付き）
- 週間貢献度、個人報酬、メンバーランキングを備えたギルド「第零共鳴団」
- 通常任務・レイドダメージ・アリーナ戦を団員全員で進める3つの共同任務
- 探索・装備生成・育成も貢献へつながり、1日1回送れる団員応援
- 40文字のギルドチャットとワンタップ定型スタンプ（端末内保存・HTML無害化）
- 1日1回受け取れる共同補給と、団員3名が応答するレイド救援要請
- 個人累積ダメージを反映するギルド内レイドランキング
- 3つの探索地と4種類の素材
- 素材を消費するキャラ・スキル・パッシブ強化と個別装備生成
- R / SR / SSR / URのガチャ、天井、重複変換
- 低音、吸引ノイズ、静寂、衝撃、ステレオ和音を重ねたガチャSE v2
- 白、黒紫、赤、黄、シアンを大胆に使った新しい指揮官カード2名
- ビビッドな色使いを共通項にした新規指揮官4名（カガリ、アオ、スズネ、ツヅリ）の全身アート
- 新規4名を召喚・所持・5人編成・個別育成・キャラ別装備へ統合
- 画像生成による任務敵・レイドボスのゲーム内アート
- プレイヤー名、プレイヤーID、累積戦闘・召喚回数を確認できるテスト用プロフィール
- セーブコードの書き出し・読み込みによる、別ブラウザ・別端末への進行共有
- 既存データを保持したままキャンペーン、プロフィール、累積戦績、スタミナ回復時刻を追加するv1.1セーブ移行

開始時の5名は「プロローグ召喚済み」という設定で、基本ユニットはガチャから取得します。ゲーム状態はブラウザへ自動保存され、メニューのセーブコードでも持ち運べます。

## 今回のプレイテスト範囲

ソロ～数名で触るためのWeb版です。ギルド、共闘ランキング、チャット、レイド全体HPなどは同一端末内で遊べる模擬データです。アプリ化、アカウントサーバー、リアルタイム同期、本番課金、規約対応はこの段階では対象外としています。
