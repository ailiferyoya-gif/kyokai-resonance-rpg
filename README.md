# 境界共鳴 Web Prototype

iPhone向けソーシャルRPG「境界共鳴」のブラウザ確認版です。GitHub Pagesでそのまま配信できる、依存関係のない静的HTML/CSS/JavaScriptで構成しています。

## 体験できる内容

- スマートフォン縦画面に最適化したホーム／任務／レイド／部隊／設定
- R〜URのガチャ、10連SR以上保証、ソフト天井、80回UR確定
- Canvas粒子、Web Audio、対応端末の振動を組み合わせたUR演出
- 隊長・兵数による基本オート戦闘、損耗、逐次ログ、戦後補充
- 点滅軽減、消音、振動OFF、召喚結果即時表示
- `localStorage`によるデモ進行保存と初期化

## 注意

抽選・戦闘はUI確認用にブラウザ内で計算しています。製品版では石消費、抽選、付与、天井、戦闘結果をサーバーで確定します。

キャラクター画像は初期コンセプトです。今後の生成では固定配色ではなくビビッドさを共通品質とし、手指を拡大検査・修正してから採用します。
